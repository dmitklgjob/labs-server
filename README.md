# Развёртывание сервера

1. Разместите Symfony в `~/www/backend`. Точка входа должна быть в `~/www/backend/public/index.php`.
2. Соберите Vue командой `npm run build` из каталога проекта. Скопируйте содержимое `dist/` в `~/www/frontend/public/` на сервере. Если сборка публикуется в другом каталоге, задайте его абсолютный путь в `FRONTEND_PUBLIC_DIR`.
3. В каталоге с Compose выполните `cp .env.example .env`. Укажите локальный IP сервера в `POSTGRES_BIND_IP` и задайте `POSTGRES_PASSWORD`.
4. В `~/www/backend/.env.local` укажите `APP_ENV=prod`, `DEFAULT_URI` с адресом сайта и `DATABASE_URL=postgresql://app:пароль@postgres:5432/app`, подставив реквизиты из файла Compose `.env`. Используйте URL-кодирование для специальных символов в реквизитах подключения. Для `APP_SECRET`, `OAUTH_PASSPHRASE` и `OAUTH_ENCRYPTION_KEY` задайте отдельные случайные значения (например, через `openssl rand -hex 32`).
5. Создайте каталоги `var`, `vendor` и `config/jwt` внутри `~/www/backend`. Дайте пользователю контейнера `www-data` (UID 33) доступ на чтение к backend и право записи в эти каталоги и в `public` для установки ресурсов Symfony.
6. Выполните первичную настройку, подставив адрес, с которого пользователи открывают сайт, и email администратора.

   ```sh
   make init OAUTH_REDIRECT_URI=http://192.168.1.10:8888/callback ADMIN_EMAIL=admin@example.com
   ```

   Команда запускает контейнеры, устанавливает зависимости Symfony, создаёт ключи OAuth, применяет миграции и регистрирует клиент Vue и администратора. Сохраните пароль администратора, который команда выводит при создании. Повторный запуск сохраняет существующие ключи и записи клиента и администратора. При смене адреса сайта обновите redirect URI существующего клиента `frontend`.

Для обновления backend после копирования файлов выполните `make composer-install`, затем `make migrations`. Отдельно можно запустить контейнеры командой `make up`.

Nginx принимает запросы на всех интерфейсах на порту `8888`. PostgreSQL доступен по настроенному локальному IP на порту `5432`. PHP подключается к нему по внутреннему имени `postgres`.

Для остановки используйте `make stop`. Том PostgreSQL сохраняется между запусками.
